# Modelos

Carpeta destinada a artefactos de modelos entrenados (pesos, scalers, metadatos).

Formatos previstos:
- `.pt` / `.pth` — pesos PyTorch
- `.h5` / `.keras` — modelos Keras
- `.pkl` / `.joblib` — scalers y objetos auxiliares
- `.json` — metadatos de configuración (window, horizon, features)

> Los archivos binarios pesados quedan excluidos del repositorio vía `.gitignore`.
